# 🎵 Плейлист-Бот (Android)

Застосунок шукає **легальну безкоштовну музику** за жанром, мовою та новизною, складає плейлист і завантажує його **прямо на флешку** (через OTG) або в будь-яку папку телефону.

## Що вміє
- **Джерела:** Jamendo (понад 600 тис. треків під Creative Commons) та Internet Archive (колекції netlabels, лише CC та Public Domain).
- **Фільтри:** 17 жанрів, мова пісень (українська, англійська, польська, німецька, французька, іспанська, італійська, російська, румунська, молдовська, інструментал), «популярні зараз» або «найновіші», «лише сучасні (з 2018)», кількість від 10 до 100.
- **Перемішування:** щоразу новий добір.
- **Перегляд перед записом:** зняти зайві галочки, утримати трек, щоб прослухати.
- **Запис на флешку:** папка з MP3 (`01 - Виконавець - Назва.mp3`), плейлист `.m3u` для автомагнітоли чи плеєра, файл `Автори_та_ліцензії.txt` (вимога ліцензій CC).

## Як отримати APK (без Android Studio)
1. Створіть безкоштовний акаунт на github.com.
2. Створіть новий репозиторій і завантажте в нього **весь вміст** цієї папки (кнопка «Add file → Upload files»; папку `.github` теж).
3. Відкрийте вкладку **Actions**: збирання «Зібрати APK» запуститься саме (приблизно 3–5 хв).
4. Відкрийте завершений запуск і внизу, в розділі **Artifacts**, завантажте `PlaylistBot-APK`. Усередині буде `app-debug.apk`.
5. Скопіюйте APK на телефон і встановіть (дозвольте «Встановлення з невідомих джерел»).

Альтернатива: відкрити папку в Android Studio і натиснути ▶ Run.

## Перший запуск
1. Натисніть «⚙ Ключ Jamendo» → devportal.jamendo.com → безкоштовна реєстрація → створіть застосунок → скопіюйте **Client ID**. Без ключа працює тільки Internet Archive.
2. Вставте флешку через OTG-перехідник.
3. Оберіть жанр і мову → «Знайти пісні» → «Обрати флешку» (меню ☰ → USB-накопичувач → «Використати цю папку») → «Завантажити».

## Важливо
- Мейнстрімні хіти (з YouTube, Spotify тощо) легально безкоштовно завантажити не можна, тому їх тут немає. Тут музика незалежних виконавців, які самі дозволили вільне поширення.
- Ліцензії Jamendo зазвичай дозволяють **некомерційне** використання. Для музики у відео на продаж чи для бізнесу потрібна окрема ліцензія (Jamendo Licensing).
- Флешка має бути у форматі FAT32 або exFAT. Перед тим як виймати, від'єднайте її в налаштуваннях телефону.

Технічно: Java, Android 8.0+ (minSdk 26), без сторонніх бібліотек, запис через Storage Access Framework.
